One job title, the weirdest we could think of — written by a small
deterministic Python program to `/output/entry.txt` for the
[Weirdest Job Title: Blind Judge Showdown](https://make.fun/bounty/u-rusdyxbt-weirdest-job-title-blind-judge-showdown-552d7922)
bounty on [make.fun](https://make.fun).

The entry: **Chief Apology Officer for Self-Driving Cars** (43 characters).

A real-sounding corporate title with one hilariously specific twist: a
chief officer whose whole job is apologizing — to cars that drive
themselves.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```

No network, no dependencies, Python 3.13 standard library only.
